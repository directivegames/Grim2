# 17 → 18

## 1. Instanced mesh paint properties renamed

The per-instance paint settings on `BaseInstancedMeshNode` (and therefore `InstancedMeshNode` and `InstancedModelMeshNode`) and their `BaseInstancedMeshNodeOptions` counterparts were renamed. `instanceDensity` is removed with no direct replacement; the new `paintWeight` is a different setting (relative weight when painting across several selected instanced meshes). No deprecated aliases remain.

| Before (17) | After (18) |
| --- | --- |
| `instanceScale` | `baseScale` |
| `instanceRotation` | `baseRotation` |
| `instanceOffset` | `baseOffset` |
| `instanceScaleDelta` | `scaleRandomization` |
| `instanceRotationDelta` | `rotationRandomization` |
| `instanceOffsetDelta` | `offsetRandomization` |
| `instanceDensity` | removed |

```ts
// Before (17)
const trees = ENGINE.InstancedModelMeshNode.create({
  instanceScale: new THREE.Vector3(1, 1, 1),
  instanceScaleDelta: 0.2,
  instanceRotationDelta: new THREE.Vector3(0, 180, 0),
  instanceDensity: 2,
});

// After (18)
const trees = ENGINE.InstancedModelMeshNode.create({
  baseScale: new THREE.Vector3(1, 1, 1),
  scaleRandomization: 0.2,
  rotationRandomization: new THREE.Vector3(0, 180, 0),
});
```

Saved scenes and prefabs are not migrated: values stored under the old names are ignored on load and the new properties fall back to their defaults. Already-painted instances (`instances`) are unaffected. Re-set the values on each node through MCP: `query_node(find, query="Instanced")` → `getEditableProperties` → `action_node(setProperties, properties={ baseScale, scaleRandomization, … })` → `action_scene(save)` → re-query (`genesys-mcp-orchestrator`); for a prefab, open it with `action_prefab.open` and flush with `action_prefab.save`. Do not hand-rename keys in `.genesys-scene` or `.prefab.json` files. With MCP Off, re-enter them in the editor's instanced-geometry toolbar.

## 2. `FogNode` getter/setter methods replaced by properties

`FogNode`'s `getFogColor/Mode/Near/Far/Density()` and `setFogColor/Mode/Near/Far/Density()` methods are removed. `fogColor`, `fogMode`, `fogNear`, `fogFar`, and `fogDensity` are now public accessors that apply to the active fog immediately. Setter chaining is no longer possible. The protected `setFogProperties()` is removed; subclasses that overrode or called it, or redeclared the `fogX` fields, must use the accessors instead. Saved scenes are unaffected.

```ts
// Before (17)
fog.setFogMode(ENGINE.FogMode.Exponential).setFogDensity(0.02).setFogColor(color);
const near = fog.getFogNear();

// After (18)
fog.fogMode = ENGINE.FogMode.Exponential;
fog.fogDensity = 0.02;
fog.fogColor = color;
const near = fog.fogNear;
```

`FogMode` gained `ExponentialHeight` (WebGPU renderer only, configured with `fogHeight` and `fogHeightFalloff`). Exhaustive `switch` statements over `FogMode` need a new case.

Reference implementations: `BaseInstancedMeshNode.ts`, `FogNode.ts` in `.engine/src/nodes/visual/`.
